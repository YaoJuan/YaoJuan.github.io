Flutter Plugin 从 CocoaPods 迁移到 SPM

项目背景

将现有的CocoaPods插件迁移到Pure Swift Package Manager架构，具体项目为flutter_mapbox_navigation插件的迁移工作。

项目信息

  • 插件名称: flutter_mapbox_navigation
  • 迁移方向: CocoaPods → Pure SPM
  • SDK版本: Mapbox Navigation SDK v3.10.2
  • Flutter版本: 3.32.4
  • 最低iOS版本: 14.0

常见问题解决

问题1: Product名称不匹配

旧命名 新命名
flutter_mapbox_navigation flutter-mapbox-navigation

错误现象: product 'flutter-mapbox-navigation' not found 错误

原因: Flutter生成的SPM配置期望Product名称使用连字符(-) 而不是下划线(_)

总结经验

通过这次Flutter插件从CocoaPods到SPM的迁移，我们学到了：

  1. SPM vs CocoaPods完全替换：Flutter现在支持纯SPM开发，不需要混合使用
  2. 命名约定很重要：连字符 vs 下划线的问题直接影响构建流程
  3. 版本冲突有标准解决方案：使用--config-only命令处理平台版本冲突
  4. 配置细节决定成败：每个配置文件的设置都很关键

随着Flutter版本更新，SPM支持会更加完善，现在的一些workaround可能在未来不再需要。
